Overview

在纯视觉 pi0.5 的基础上，把夹爪指尖的视触觉图像加入策略输入。 以接触前后的图像差异为线索，比较不同触觉编码和处理方式， 并在 Piper 机械臂上验证抓取与放孔。

纯视觉基线

复刻 pi0.5 的抓桶流程，确认视觉策略、相机和机械臂链路正常。

加入视触觉

把两只指尖的触觉图作为额外输入，利用接触前后的差异判断夹爪与物体的接触状态。

接触感知微调

从原始触觉策略继续训练 encoder、action LoRA 和 action head，让触觉 token 参与动作生成。

触觉编码与微调

触觉 encoder 由空间卷积和时间卷积组成，输出 4 个 token。 微调时训练触觉 encoder、action LoRA 和 action head，语言与视觉主干保持冻结。

AnyTouch2 adapter-only

冻结预训练触觉特征，只训练轻量 adapter。参数少，但触觉对动作的影响有限。
